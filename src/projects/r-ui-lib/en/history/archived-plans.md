# Archived plans and proposals

The original UI Toolkit PRD and foundation plan describe how the library was expected to grow. They are historical project records, not API references or release promises.

## Current status

The maintained library now includes component layouts, controls, themes, item selection, a development playground, and Forge 1.20.1 / NeoForge 1.21.1 support. Check the [component guide](../technical/components-and-themes) and the current library sources for the released API.

The historical plans contain larger proposed APIs, milestones, and future component lists. Treat any proposal as unimplemented unless it is covered by the current integration guide or the target release's public API.

Original documents are kept with the R-Ui Lib source repository:

- [Minecraft UI Toolkit PRD](https://github.com/radaelilucca/mc-r-ui-lib/blob/main/docs/minecraft-ui-toolkit-prd.md)
- [UI Toolkit foundation plan](https://github.com/radaelilucca/mc-r-ui-lib/blob/main/docs/ui-toolkit-foundation-plan.md)
