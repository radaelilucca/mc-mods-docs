# R-Ui Lib

A R-Ui Lib oferece aos mods de Minecraft um conjunto compartilhado de componentes reutilizáveis para criar telas claras e consistentes. Ela não adiciona telas, blocos ou itens próprios; os jogadores a veem por meio dos mods que dependem dela.

| Minecraft | Loader | Versão mínima |
| --- | --- | --- |
| 1.20.1 | Forge | 47.4.20 |
| 1.21.1 | NeoForge | 21.1.236 |

## Para jogadores

Instale a biblioteca junto com um mod compatível que a exija, usando as mesmas versões de Minecraft e loader. O mod que utiliza a biblioteca determina quais telas e recursos estão disponíveis.

[Instalação e requisitos](./player/)

## Para desenvolvedores

Crie telas com layouts, controles interativos, componentes de seleção de itens e temas visuais compartilhados. O mesmo código dos componentes atende aos alvos Forge e NeoForge listados.
