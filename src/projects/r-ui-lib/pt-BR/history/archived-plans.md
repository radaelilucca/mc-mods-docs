# Planos e propostas arquivados

O PRD original do UI Toolkit e o plano de fundação descrevem como a biblioteca deveria crescer. Eles são registros históricos do projeto, não referências de API nem promessas de lançamento.

## Status atual

A biblioteca mantida hoje inclui layouts de componentes, controles, temas, seleção de itens, um playground de desenvolvimento e suporte a Forge 1.20.1 / NeoForge 1.21.1. Consulte o [guia de componentes](../technical/components-and-themes) e o código atual da biblioteca para conhecer a API publicada.

Os planos históricos contêm APIs propostas, etapas e listas de componentes futuros. Considere uma proposta como não implementada até estar descrita no guia de integração atual ou na API pública da versão desejada.

Os documentos originais estão no repositório de fontes da R-Ui Lib:

- [PRD do Minecraft UI Toolkit](https://github.com/radaelilucca/mc-r-ui-lib/blob/main/docs/minecraft-ui-toolkit-prd.md)
- [Plano de fundação do UI Toolkit](https://github.com/radaelilucca/mc-r-ui-lib/blob/main/docs/ui-toolkit-foundation-plan.md)
