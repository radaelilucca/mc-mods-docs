# Sophisticated Backpacks: Digital Storage Expansion

[![CurseForge](https://cf.way2muchnoise.eu/title/1742266.svg)](https://www.curseforge.com/minecraft/mc-mods/sophisticated-backpacks-digital-storage-expansion)

Connect Sophisticated Backpacks to an existing digital storage network. The mod adds eight function-specific upgrades, each using the same linking system with Applied Energistics 2, Refined Storage, or Tom's Simple Storage. On NeoForge 1.21.1, the upgrades also support SCC 1.5.3 or newer. The mod does not add a storage network of its own.

Each upgrade links to one network endpoint and follows that network's range and access rules. Item upgrades work with all four networks where supported; Remote Pump supports fluids with AE2 and Refined Storage on both loaders, and SCC on NeoForge. Tom's Simple Storage is item-only.

**Documented version:** 0.3.0

**Minecraft:** 1.20.1 (Forge) and 1.21.1 (NeoForge)
