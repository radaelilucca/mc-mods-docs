# Install and use

Install Digital Storage Expansion on both the client and server, with the matching Sophisticated Backpacks and Sophisticated Core versions.

| Minecraft | Loader | Sophisticated Backpacks | Sophisticated Core |
| --- | --- | --- | --- |
| 1.21.1 | NeoForge 21.1.236 or newer | 3.26.3 or newer | 1.5.1 or newer |
| 1.20.1 | Forge 47.4.10 or newer | 3.26.12 or newer | 1.5.10 or newer |

Choose any supported storage mod and its compatible version for your game and loader:

| Network | 1.21.1 NeoForge | 1.20.1 Forge |
| --- | --- | --- |
| Applied Energistics 2 | 19.2.18 or newer | 15.4.11 |
| Refined Storage | 2.0.9 or newer | 1.12.4 |
| Tom's Simple Storage | 2.4.2 or newer | 1.7.1 |
| Super Cool Calculator (SCC 1.5.3+) | NeoForge 1.21.1 | Not supported |

Storage mods are optional dependencies. You can install more than one; each upgrade remains linked to the network you selected for it. All four networks support item upgrades where available. Remote Pump's fluid transfer works with AE2 and Refined Storage on both loaders, and SCC on NeoForge; Tom's Simple Storage is item-only. Full in-game validation of SCC gameplay is still pending.

## First steps

1. Craft one of the eight remote upgrades from its matching advanced Sophisticated Backpacks upgrade, 3 diamonds, 2 Ender Pearls, and 2 redstone dust.
2. Hold that upgrade and **Shift-right-click** a compatible network block. Use an ME Wireless Access Point for AE2, a Controller for Refined Storage, a Storage Terminal for Tom's Simple Storage, or a Network Antenna for SCC on NeoForge 1.21.1.
3. Put the linked upgrade into a backpack upgrade slot and open its tab to configure it.
4. Use the upgrade's controls or automatic behavior in game. See [Linking](linking), [Filters and source priority](filters), and the [upgrade catalog](upgrades).

The upgrade uses the network's own wireless setup, range, and permissions. Linking does not grant access that your network would otherwise deny.

See [Configuration](configuration) for the mod's configuration-file status.
