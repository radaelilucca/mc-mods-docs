# Configuration

Version 0.3.0 does not add player- or server-editable configuration files of its own. There is no Digital Storage Expansion TOML, JSON, or other config file to create or edit.

The upgrade's filters, source priority, and function settings are saved on each upgrade item and changed in its backpack tab. For details, see [Filters and source priority](filters) and the [upgrade catalog](upgrades).

Remote Pump uses the Sophisticated Backpacks pump settings for its fluid filter slots and throughput calculation. Those settings belong to Sophisticated Backpacks, not this addon; consult that mod's configuration documentation for their file location, defaults, and reload behavior.
